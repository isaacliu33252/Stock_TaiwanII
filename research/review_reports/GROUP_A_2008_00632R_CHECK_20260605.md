# Group A 2008 00632R Check 2026-06-05

資料區間：2007-07-02 至 2010-12-31。  
方法：TWII proxy stress test，不是真實 0050 / 00631L / 00632R 歷史 ETF 資料。

Proxy:

- 0050 = 1x TWII daily return
- 00631L = 2x TWII daily return
- 00632R = -1x TWII daily return

## Conclusion

2008 proxy stress test **不支持禁用 00632R**。

這和 2024~2026 回測相反：

- 2024~2026：禁用 00632R 轉 0050，報酬與 Sharpe 明顯改善，但 MDD 變差。
- 2008 proxy：禁用 00632R 轉 0050，final、Sharpe、MDD 全部變差。

## Recommendation

不要把 `disable 00632R -> 0050` 當成無條件正式規則。

比較穩健的判斷：

- 一般市場 / 2024~2026 類型：降低或禁用 00632R 有利報酬。
- 2008 型壓力市場：保留短期 00632R hedge 比禁用好。

因此 Group A 更合理的下一版不是永久禁用 00632R，而是：

1. 保留 `destination_primary`。
2. 00632R 不完全禁用。
3. 優先考慮 `hold_limit_00632R_10d_to_0050` 或「正常市場禁用、壓力市場允許」的條件式規則。
