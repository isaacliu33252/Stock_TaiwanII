## 論文方法論摘要

- 定義「理性泡沫」：多數新進場投資人只因為過去價格上漲而投資（追高行為）。
- 假設所有投資人投資市場組合，用連續形式積分求出在價格點p_x時全體投資人的平均報酬E(R)（分子分母都用「以價格加權的成交量」regression line近似成交量分佈，v=ap+b，a/b由價格與成交量的相關係數、標準差、平均數推導）。
- 核心邏輯：當市場報酬MR(p_x)=p_x/p_0 開始超過投資人平均報酬E(R)時，代表大多數投資人的組合報酬其實落後大盤（因為沒人買在最低點），這個「期待落空」的心理狀態使市場進入脆弱期，小幅價格波動就可能引發massive crash。求解MR(pα)=E(R)得到不穩定區間的起點pα。
- 應用在道瓊指數(1999-2021)、比特幣(2016-2021)，宣稱成功「預測」2008金融危機、2020崩盤（道瓊），以及2017、2021兩次比特幣崩盤。

## 為何不適用（三個獨立理由，任一都足夠關閉）

### 1. 核心實作方法自稱「機密」，完全無法複製驗證
論文Section 3開頭與3.2兩次明講：「Although the specific methodology that been used for this paper's trial is confidential」——用來處理成交量離散化regression問題、以及求解`MR(pα)=E(R)`方程式（含log項，一般solver解不出來）的具體數值方法完全沒有公開。這代表論文唯一有實用價值的部分（數學推導如何落地成可執行的預測演算法）從缺，無從重建、無從測試、無從驗證其宣稱的預測成功案例是否可信。

### 2. 評估方式不嚴謹，且論文自己承認大範圍偽陽性
- 「The model's performance is assessed visually」——純肉眼判斷，沒有precision/recall、沒有Sharpe、沒有統計顯著性檢定、沒有跟LPPL（論文自己提到的既有方法）或任何baseline比較。
- 論文自己承認：模型把2020年中到2021年中**整整一年**標記為「崩盤前兆」，結果沒有崩盤，作者猜測是「specificity比預期低」或「處理大價格跳動時出錯」。
- 論文自己承認：模型會把「崩盤發生後的短期波動」誤判成「崩盤事件本身」，作者僅以「this error can be easily adjusted by human evaluator」帶過，沒有提出任何工程化修正方案。

### 3. 作者背景與發表管道
Soongsil University（韓國崇實大學）金融系**大學部學生**（UG student），單一作者，2021年掛上arXiv後無後續版本更新、無可查證的期刊發表或後續引用紀錄，屬於未經同儕審查的早期習作等級論文。

### 4. 市場不同（次要，未列入關閉主因）
道瓊指數與比特幣，跟台股ETF（0050/00631L/00632R/00679B）的結構、流動性、法規環境、成交量分佈特性都不同，即使方法論公開也需要重新校準參數，但此點是次要問題，前三項已足夠關閉。
